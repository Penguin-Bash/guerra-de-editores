Esta mini web es un guiño a la eterna rivalidad que hay entre los usuarios de Emacs y los usuarios de Vi (vim o neovim). 
Puede servir también como pequeña fuente informativa para usuarios que todavía no sepan de esta rivalidad.

Para acceder cómodamente al contenido, se puede usar el siguiente enlace:

https://penguin-bash.github.io/guerra-de-editores/
